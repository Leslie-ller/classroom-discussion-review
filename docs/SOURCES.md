# 资料与示例

本仓库发布模块实现与自行构造的两份讨论输入。没有打包私人课堂记录、模型完整请求、认证文件或开发阶段的数据集快照。

开发阶段曾参考：

- [MathDial](https://github.com/eth-nlped/mathdial)：真人教师与模拟学生讨论。原项目数据协议为CC BY-SA 4.0；本公开版本不重发该数据。
- [Wikibooks Basic Algebra](https://en.wikibooks.org/wiki/Basic_Algebra)及基础数学教材：用于课程资料检索实验；不附带教材全文。
- [JWST流水线文档](https://jwst-pipeline.readthedocs.io/en/1.18.x/)：用于资料版本、源类型与适用条件边界检查；不附带文档快照。

这些来源与小样本开发运行不构成本仓库的总体准确率评测。`examples/`是格式与功能输入，示例页没有预置“成功”的模型结果。使用者应在自己的模型与课程资料上独立验证。
